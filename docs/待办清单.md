### B6 实现要点（2026-10-20 摸过代码，记下来免得重查）

- 列定义与持久化在 `src/components/purchase/usePurchaseColumns.js`：
  `DEFAULT_COLUMNS` / `OPTIONAL_COLUMNS` / `ALL_COLUMNS`、localStorage 键 `hnd-purchase-columns`、
  导出的 `orderedColumns`（现在按 `ALL_COLUMNS` 的固定顺序过滤可见列 ⇒ **顺序不可调**就卡在这里）
- 下拉框在 `src/components/purchase/PurchaseColumnPicker.vue`（勾选框列表）
- 改法：把「可见集合」升级成「**有序数组**」（localStorage 里存 key 的顺序），
  `orderedColumns` 直接按这个数组输出；下拉框每项加 ▲▼（或拖拽）+ 已勾选项前面显示 `第 n 列` 的序号。
  **迁移**：老 localStorage 里只有 key 集合 ⇒ 读到时按 `ALL_COLUMNS` 补全顺序，别让老用户白屏。
- 护栏：`tests/unit/purchaseColumns.spec.js`（9 条）会跟着改；设备页若有同款 picker（`equipmentColumns.spec.js` 存在）**一起做**，别只改一处。
- ⚠️ 顺序影响表头与 `table-fixed` 的列宽预算：`usePurchaseColumns.js` 头部注释里那段「8 列必须 ≤ 1100px」的账要跟着重算。
